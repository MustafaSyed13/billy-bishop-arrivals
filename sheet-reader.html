The morning log sheet is filled in by hand and then re-typed into a spreadsheet. This is a demonstration of software that reads the handwriting instead, checks every value against what is already known about the flight, and hands back a line ready to paste.

Everything on this page is made up. It runs entirely inside your browser on sample values, uploads nothing, and stores nothing. No real sheet, no real flight data, and no photograph is involved. The working tool runs offline on a single computer and is not part of this website.

Why a plain reader is not enough

Optical character recognition on its own gives you the digits and nothing else. It cannot tell that a passenger reaching the hall before the aircraft landed is impossible, or that 18 written beside a ten o'clock arrival means eighteen minutes past ten. Those judgements need context the reader does not have.

This system supplies that context from the arrivals data it already holds — the real flight numbers for the day, and the arrival times observed from the aircraft's own position signal. Reading the sheet stops being open-ended guesswork and becomes matching against a short list of things each line could legally be.

What it refuses to do

A correction is only applied when exactly one reading survives every check. Where two readings would both fit, the cell is flagged and a person decides. Guessing between them is how software quietly invents data, which would be far worse than leaving the typing alone.

It also protects the signal the sheet exists to capture. An hour between the aircraft landing and the first passenger is unusual, but it is real — it is what a blocked gate looks like. That row is raised for confirmation and never rewritten into a tidier number.

Every cell carries its own confidence, so a supervisor can see which entries to check rather than having to trust or distrust the whole sheet. The original text is always kept: when someone asks what the paper actually said, the answer has not been overwritten by a correction.

Where it runs

  • On one computer, offline. The photograph is read by a model on that machine and does not leave it.
  • Nothing is uploaded to this website, and this page has no connection to the tool.
  • Output is a line of text, copied and pasted into the existing workbook. No system is replaced and no process changes.
